# Insurance Cost Predictor

A machine learning project that predicts medical insurance charges based on patient information such as age, BMI, smoking status, region, and number of dependents.

## Technologies Used

- Python
- Pandas
- Scikit-Learn
- Streamlit
- Joblib

## Features

- Interactive Streamlit web application
- Insurance cost predictions
- Data cleaning and preprocessing
- Machine learning regression model (R² = 0.876)

## Model Performance

The final regression model achieved an R² score of 0.876 on the test set.

## Files

- app.py - Streamlit application
- analysis.py - data exploration
- cleaning.py - data preprocessing
- train_final_model.py - model training
- final_model.pkl - trained model
